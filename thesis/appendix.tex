The \texttt{force2D} setting was required because the input images are single 2D ultrasound slices stored as 3D arrays with depth $= 1$. Without this setting, PyRadiomics attempts 3D co-occurrence calculations that fail on single-slice volumes. Shape features were disabled because the region-of-interest masks were manually drawn by clinicians to delineate the pancreas graft boundary; shape features would therefore reflect annotation style rather than tissue properties.

The bin width of 25 discretises intensity values into bins of width 25 grey levels for texture matrix computation. This is the PyRadiomics default and was not optimised for this application. The Image Biomarker Standardisation Initiative (IBSI) \cite{zwanenburg2020} provides reference values computed with this configuration, enabling comparison with other studies using IBSI-compliant extraction.

## Writing rules

1. **Verify before writing.** Never write a number from memory. Open the source CSV and confirm. Previous audit found 13 errors in a single chapter draft.
2. **Use booktabs.** All tables use `\toprule`, `\midrule`, `\bottomrule`. No vertical rules.
3. **Feature names in monospace.** Use `\texttt{feature\_name}` for all feature names.
4. **Underscore escaping.** Feature names contain underscores - always use `\_` in text mode.
5. **Round consistently.** p-values to 3 decimal places (0.053, not 0.05326). AUC to 3 decimal places. Effect sizes to 2 decimal places.
6. **British spelling.** The thesis uses British English (behaviour, generalisation, standardisation).
7. **No hallucinated citations.** Every `\cite{}` must have a matching `bibliography.bib` entry verified against a real DOI or PubMed record.
8. **Negative result framing.** The main radiomics finding is negative (no signal). Write this clearly and directly - do not oversell or hedge excessively.
9. **Cross-reference labels.** Use `\ref{tab:...}` and `\ref{fig:...}` for all internal references.
10. **Compile after every section.** Run latexmk and check for errors before moving on.

## Bibliography rules

- Never write a bib entry from training data. Verify title, authors, journal, year, volume, pages against the DOI or PubMed.
- Use the `others` shorthand for author lists longer than 3-4 names.
- Protect acronyms/proper nouns with braces: `{ARFI}`, `{Banff}`, `{US}`.
- Current entries: 20 total (see `thesis/bibliography.bib`).

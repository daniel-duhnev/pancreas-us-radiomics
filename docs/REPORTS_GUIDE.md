## Regeneration

All reports can be regenerated by running the corresponding notebook top-to-bottom with kernel `thesis_env`. Notebooks read from `data/` (gitignored), so data must be present locally.

Quick regeneration order (for normalised results):
1. NB 12 normalised (feature extraction - takes 2-3 minutes)
2. NB 13 normalised (merge - instant)
3. NB 14a normalised + NB 18 normalised (can run in parallel after step 2)
4. NB 19, 20, 21 normalised (after step 3)

## Migration

When moving to a new machine, either:
- Copy the entire `analysis/reports/` folder (fastest), or
- Copy `data/` and re-run notebooks in sequence

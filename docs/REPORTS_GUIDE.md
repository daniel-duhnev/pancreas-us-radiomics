## Regeneration

All reports can be regenerated by running the corresponding notebook top-to-bottom with kernel `thesis_env`. The notebooks read from `data/` (gitignored) so data must be present locally.

## Migration

When moving to a new machine: either copy `analysis/reports/` wholesale, or just copy `data/` and re-run notebooks 12-21 in sequence.
